## 🇫🇷 Français

### ⚙️ Guide d'Installation

Suivez ces étapes simples pour installer et utiliser le moniteur de commandes :

1. **Extraction :** Extrayez le contenu de l'archive zip `OrderMonitor` dans le dossier suivant de votre répertoire Steam :
`\steamapps\common\Fast Food Simulator\ProjectBakery\Binaries\Win64\`
2. **Initialisation :** Lancez *Fast Food Simulator* une première fois pour initialiser les fichiers, puis quittez le jeu.
3. **Lancement du moniteur :** Naviguez jusqu'au dossier nouvellement créé :
`\steamapps\common\Fast Food Simulator\ProjectBakery\Binaries\Win64\Mods\OrdersMonitor\`
Double-cliquez sur le fichier **`OrdersMonitor.html`** pour l'ouvrir dans votre navigateur web.
4. **Profitez :** Ressentez l'efficacité de votre nouveau système 🔥 !

## 🇬🇧 English

### ⚙️ Installation Guide

Follow these simple steps to install and use the order monitor:

1. **Extract:** Extract the contents of the `OrderMonitor` zip file into the following folder within your Steam directory:
`\steamapps\common\Fast Food Simulator\ProjectBakery\Binaries\Win64\`
2. **Initialize:** Run *Fast Food Simulator* once to initialize the mod files, and then exit the game.
3. **Launch the monitor:** Navigate to the newly created folder:
`\steamapps\common\Fast Food Simulator\ProjectBakery\Binaries\Win64\Mods\OrdersMonitor\`
Double-click the **`OrdersMonitor.html`** file to open it in your web browser.
4. **Enjoy:** Feel the efficiency of your new system 🔥!
