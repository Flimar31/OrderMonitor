# 🍔 Fast Food Game Plugin

## 🇫🇷 Français

Bienvenue sur le README du plugin **Fast Food**. Ce plugin a été conçu pour fluidifier la gestion de votre restaurant en attribuant des codes couleurs spécifiques selon la provenance de la commande (Salle ou Drive) et la station de préparation.

### Comment fonctionne le plugin ?

Le système repose sur des indicateurs visuels. Lorsqu'une commande est passée, une couleur lui est assignée. Cette couleur permet à votre équipe de savoir instantanément **pour quel service** la commande est destinée et **quelle station** doit la préparer.

Il vous suffit de suivre la couleur associée à votre poste pour savoir quelles tâches vous incombent.

### 🎨 Le Code Couleur

Voici le tableau récapitulatif des couleurs attribuées aux différentes stations selon le type de service :

| Type de Service | Station à préparer | Indicateur de Couleur |
| --- | --- | --- |
| **🍽️ Salle** | Hamburger + Bar | ⚪ **Blanc** |
| **🍽️ Salle** | Comptoir | 🟡 **Jaune** |
| **🚗 Drive** | Hamburger + Bar | 🔵 **Bleu** |
| **🚗 Drive** | Comptoir | 🟣 **Violet** |

### 📦 Détails du poste "Comptoir"

Le comptoir est le point névralgique de votre fast-food. Si vous êtes assigné au **Comptoir** (couleurs 🟡 ou 🟣), vous êtes en charge des éléments suivants :

* **Salle** (Gestion et service)
* **Boissons**
* **Frites**
* **Nuggets**
* **Glaces**

## 🇬🇧 English

Welcome to the **Fast Food** plugin README. This plugin is designed to streamline your restaurant's workflow by using a specific color-coding system based on the order's origin (Dine-in or Drive-thru) and the preparation station.

### How does the plugin work?

The system relies on visual indicators. When an order is placed, a color is assigned to it. This color allows your team to instantly know **which service** the order is for and **which station** needs to prepare it.

Simply follow the color assigned to your station to know exactly which tasks you need to handle.

### 🎨 The Color Code

Here is the breakdown of the colors assigned to different stations based on the service type:

| Service Type | Preparation Station | Color Indicator |
| --- | --- | --- |
| **🍽️ Dine-in (Salle)** | Hamburger + Bar | ⚪ **White** |
| **🍽️ Dine-in (Salle)** | Counter (Comptoir) | 🟡 **Yellow** |
| **🚗 Drive-thru (Drive)** | Hamburger + Bar | 🔵 **Blue** |
| **🚗 Drive-thru (Drive)** | Counter (Comptoir) | 🟣 **Purple** |

### 📦 "Counter" Station Details

The counter (Comptoir) is the central hub of your fast food restaurant. If you are assigned to the **Counter** (colors 🟡 or 🟣), you are responsible for the following items:

* **Dine-in management** (Salle)
* **Drinks** (Boissons)
* **Fries** (Frites)
* **Nuggets**
* **Ice Cream** (Glaces)
